# Daniel von Malmborg — Portfolio

Portfolio website for photographer and creative producer Daniel von Malmborg.

Built by [Joel Järvi](https://joeljarvi.com), 2026.

## Stack

- [Next.js](https://nextjs.org/)
- [Sanity](https://www.sanity.io/) — content management
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/) — UI components
- [Lenis](https://lenis.darkroom.engineering/) — smooth scroll

## Fonts

- **Diatype** by [Dinamo](https://abcdinamo.com/) — primary typeface

## Content Model

- Projects with support for dual agency/end-client relationships
- CV/biography modeled as singletons
